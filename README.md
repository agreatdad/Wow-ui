# Wow HUD

Wow HUD is a RuneLite plugin that adds an MMO-style interface overlay for Old School RuneScape.

## Features

- MMO-style portrait HUD
- HP, Prayer, Run Energy, and Special Attack bars
- Optional portrait sprite or local profile image
- Paperdoll equipment overlay
- Skills tab overlay
- Segmented progress bars
- Editable menu-stone keybind labels

## Development

Run the plugin locally with:

```bash
./gradlew run
```

On Windows:

```powershell
.\gradlew.bat run
```
